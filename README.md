# 🏢 Employee Management System
> Vue.js + Axios + MockAPI + Bootstrap  
> CBIT WP Assignment II, 2025-26

---

## 📋 Features
- **CRUD Operations**: Create, Read, Update, Delete employees via MockAPI
- **Live Search**: Filter by name or designation
- **Department Filter**: Dropdown to filter by department
- **Stats Dashboard**: Total employees, departments, average & total payroll
- **Toast Notifications**: Success/error feedback for every action
- **Responsive UI**: Bootstrap 5 with custom styling
- **Form Validation**: Client-side validation with inline error messages

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Framework | Vue 3 (Options API) |
| HTTP Client | Axios |
| UI Library | Bootstrap 5 + Bootstrap Icons |
| Backend Mock | MockAPI.io |
| Build Tool | Vite |

## 🚀 Setup Instructions

### Step 1: Clone & Install
```bash
git clone https://github.com/YOUR_USERNAME/employee-management-system.git
cd employee-management-system
npm install
```

### Step 2: Create MockAPI Resource
1. Go to [https://mockapi.io](https://mockapi.io) and sign up
2. Create a new **Project**
3. Add a new **Resource** named `employees`
4. Add these fields:
   | Field | Type |
   |-------|------|
   | name | String |
   | designation | String |
   | department | String |
   | salary | Number |
5. Copy your endpoint URL (looks like: `https://abc123.mockapi.io/api/v1/employees`)

### Step 3: Configure API URL
Open `src/services/employeeService.js` and replace:
```js
const BASE_URL = 'https://YOUR_PROJECT_ID.mockapi.io/api/v1/employees'
```
with your actual MockAPI endpoint URL.

### Step 4: Run the App
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
